# Playbook — OpenFeature setup

1. Add `cfg/feature-flags/openfeature.json` and catalog (`catalog.example.json`).
2. Choose provider (`in-memory` local; vendor in higher environments).
3. Replace ad-hoc env booleans for product behavior with flag keys.
4. Default to safe values; document flag owners.
5. Complete `openfeature-adherence.md` checklist.
